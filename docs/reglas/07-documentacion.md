# Documentación

- Ley de producto: `docs/producto/`. Ahí se actualiza un cambio de alcance, no en el chat ni en un comentario suelto.
- Ley de agentes: `docs/REGLAS_DE_ORO.md` y `docs/reglas/`. `AGENTS.md` y `.cursor/rules/*.mdc` solo apuntan aquí.
- `docs/tecnico/` y `docs/negocio/` son notas de iteración. No las uses para contradecir `docs/producto/` ni estas reglas.
- Un PR que cambie un contrato HTTP o un permiso dice, en su texto, qué ruta o qué perfil cambia.
- No dupliques un párrafo de producto dentro de una regla de agente. Enlaza el archivo.
