1. Perfil de Arquitecto de Software
Pensamiento sistémico y estratégico

Visión de extremo a extremo: desde requisitos de negocio hasta infraestructura

Toma de decisiones arquitectónicas con trade-offs (escalabilidad vs. simplicidad vs. costo)

Diseño de sistemas distribuidos, microservicios, event-driven y monolíticos modulares

Conocimientos técnicos

Patrones de arquitectura: CQRS, Event Sourcing, Hexagonal, Clean Architecture, DDD

Experto en Experiencia de Usuario (UX)
Fundamentos de UX
Investigación de usuarios: entrevistas, encuestas, jobs-to-be-done, mapas de empatía

Arquitectura de información: jerarquía, navegación, agrupación lógica de métricas

Diseño de interacción: flujos, estados, feedback, manejo de errores

Usabilidad y accesibilidad: WCAG 2.2, contraste, navegación por teclado, lectores de pantalla

Testing con usuarios: tests moderados/no moderados, A/B testing, heurísticas de Nielsen

UX aplicada a Dashboards y Datos (Data UX)
Jerarquía visual de métricas: qué se ve primero (KPI hero → tendencias → detalle)

Storytelling con datos: narrativa guiada, no solo gráficos sueltos

Diseño de dashboards por audiencia: ejecutivo (resumen), operativo (acción), analista (exploración)

Selección de visualizaciones: cuándo usar barras, líneas, heatmaps, bullet charts, sparklines

Progressive disclosure: resumen → filtros → drill-down → detalle

Diseño de filtros, alertas y estados vacíos/carga/error

Anti-patrones: pie charts abusivos, sobrecarga cognitiva, vanity metrics, dashboards "sala de servidores"

UX + AI (diferenciador clave)
Interfaces conversacionales: consultas en lenguaje natural sobre indicadores ("¿cómo van las ventas en Chile este trimestre?")

Explicabilidad: mostrar por qué un modelo/indicador cambió (drivers, anomalías)

Human-in-the-loop: confianza calibrada, corrección de sugerencias AI

Diseño de prompts y microcopy para asistentes de datos

Personalización adaptativa sin caer en cajas negras

Herramientas y entregables
Figma, FigJam, Miro, Maze, Hotjar, Optimizely

Design systems y componentes reutilizables para dashboards

Wireframes, prototipos, user journeys, mapas de calor

Mentalidad
Diseñar con el usuario, no para el usuario

Iteración basada en evidencia (métricas de uso del dashboard: adopción, tiempo a insight, frecuencia)

Balance entre estética, claridad y densidad de información

Matriz consolidada de las 5 dimensiones
Dimensión	Foco	Entregable típico
Arquitecto	Sistema completo, escalabilidad, decisiones	ADRs, diagramas C4, roadmap técnico
Desarrollador	Código limpio, APIs, CI/CD, testing	Repos, pipelines, servicios
Especialista BI/Dashboards	KPIs, modelado, visualización	Modelo semántico, dashboards, catálogo de métricas
Experto UX	Usabilidad, accesibilidad, adopción	Prototipos, design system, tests de usuario
AI	Automatización, predicción, NL	Copilots, RAG, forecasting, anomalías
Perfil "T-shaped" actualizado
Vertical profundo: arquitectura + desarrollo + BI + UX

Horizontal amplio: cloud, datos, AI, negocio, diseño

Diferenciador único: es la persona que conecta el "por qué" del negocio, el "cómo" técnico, el "qué" de los datos y el "para quién" de la experiencia, y lo acelera con AI.

En la práctica, este perfil completo es raro en una sola persona (suele ser un equipo: arquitecto + dev + BI + UX). Lo valioso es que sepa orquestar las 5 dimensiones, aunque no sea experto nivel 10 en todas.

Cloud (AWS/Azure/GCP): serverless, contenedores, Kubernetes, IaC (Terraform, Pulumi)

Seguridad, observabilidad, resiliencia y gestión de datos (OLTP vs. OLAP)

Habilidades blandas

Comunicación con stakeholders no técnicos

Liderazgo técnico y mentoría

Documentación de decisiones (ADRs) y visión a largo plazo

2. Perfil de Desarrollador de Software
Fundamentos sólidos

Algoritmos, estructuras de datos, diseño de APIs (REST/GraphQL/gRPC)

Dominio de al menos un stack backend (Python, Java/Kotlin, Node/TS, Go, C#) y frontend (React, Vue, Angular)

Testing (unitario, integración, E2E), CI/CD, Git flow, code review

Buenas prácticas

Código limpio, SOLID, refactorización, deuda técnica controlada

DevOps: pipelines, Docker, monitoreo, logging

Seguridad: OWASP, autenticación/autorización (OAuth2, OIDC)

Mentalidad

Orientado a producto y al usuario, no solo a "picar código"

Aprendizaje continuo y adaptabilidad tecnológica

3. Especialista en Dashboards de Indicadores de Negocio (BI/Analytics)
Modelado y métricas

Definición de KPIs, OKRs y métricas accionables (SMART)

Modelado dimensional (star schema, snowflake), semantic layer

Conocimiento de dominios de negocio: finanzas, ventas, operaciones, marketing, RRHH

Herramientas y visualización

Power BI, Tableau, Looker, Metabase, Superset, Grafana

SQL avanzado + dbt para transformaciones

Diseño de UX de datos: jerarquía visual, storytelling con datos, dashboards ejecutivos vs. operativos

Data engineering básico

ETL/ELT, data warehouses (Snowflake, BigQuery, Redshift), lakehouse

Calidad de datos, gobierno y linaje

4. El "Plus" de AI (perfil moderno 2025+)
Uso de copilots y LLMs en el ciclo de desarrollo (generación de código, revisión, testing, documentación)

RAG y asistentes para consultar indicadores en lenguaje natural sobre los dashboards

ML/analítica predictiva: forecasting de KPIs, detección de anomalías

MLOps básico: integración de modelos en pipelines de datos

Prompt engineering y evaluación de modelos para casos de negocio

Conocimiento de AI governance y sesgos en métricas automatizadas

5. Competencias Transversales Clave
Dimensión	Qué se espera
Producto	Traducir preguntas de negocio en métricas y soluciones técnicas
Comunicación	Explicar arquitectura y datos a audiencias mixtas
Liderazgo	Influir sin autoridad, mentoría, decisiones técnicas
Curiosidad	Aprender stacks nuevos y dominios de negocio rápido
Ética	Privacidad de datos, sesgos, transparencia en métricas
6. Combinación "ideal" (T-shaped)
Vertical profundo: arquitectura + desarrollo backend/frontend + BI

Horizontal amplio: cloud, datos, AI, negocio, UX

Diferenciador: capacidad de unir el "por qué" del negocio con el "cómo" técnico, y automatizar con AI la generación, monitoreo y explicación de indicadores.
